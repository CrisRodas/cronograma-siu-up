# Cronograma Rediseño SIU - UP

Cronograma interactivo del proyecto **Rediseño SIU UP** (basado en el Excel del proyecto).
Mismo formato que el cronograma SIU-OPM: Gantt, hitos, ruta crítica, swimlane por recurso,
mapa de dependencias, semáforo semanal y gráficas de resumen.

## Características

- 📅 **Fecha de inicio editable**: cambia la fecha en el control superior y todo el cronograma
  (fechas, Gantt, hitos, semáforo) se recalcula automáticamente respetando predecesoras y días hábiles.
- ✏️ **% de avance por tarea** editable, con persistencia en el navegador (localStorage).
- 🔴 Detección automática de retrasos y tareas vencidas según la fecha de hoy.
- 🖨️ Optimizado para impresión / exportar a PDF (A3 horizontal).
